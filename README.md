# Virtual Tour Creator

Eine einfache Anwendung zum Erstellen von virtuellen 360° Touren mit verschiedenen Hotspot-Typen.

## Installation

### Voraussetzungen

- Node.js (Version 16 oder höher)
- npm oder yarn

### Schritte zur Installation

1. Repository klonen oder herunterladen
   \`\`\`
   git clone https://github.com/AlSidHuseenMostafa/Rundgang.git
   cd Rundgang
   \`\`\`

2. Abhängigkeiten installieren
   \`\`\`
   npm install
   \`\`\`
   oder
   \`\`\`
   yarn install
   \`\`\`

3. Anwendung starten
   \`\`\`
   npm run dev
   \`\`\`
   oder
   \`\`\`
   yarn dev
   \`\`\`

4. Öffne die Anwendung im Browser unter `http://localhost:5173`

## Nutzung

1. Erstelle ein neues Projekt
2. Lade Panorama-Bilder hoch
3. Füge Hotspots hinzu (Navigation, Bilder, Videos, Info, Links, iFrames)
4. Exportiere deine Tour als ZIP-Datei
5. Veröffentliche die exportierte Tour auf deinem Webserver
